# 🚀 Edukad (پلتفرم درخت مهارت هنرستان استارتاپی رکاد)

پلتفرم **Edukad**، یک سیستم پیشرفته‌ی مدیریت مسیرهای یادگیری و مأموریت‌های واقعی است که به‌طور اختصاصی برای هنرستان استارتاپی **رکاد** توسعه یافته است. در Edukad، رویکرد آموزش‌های خطی (لیست‌های خسته‌کننده) کنار گذاشته شده و به جای آن از مفهوم **درخت مهارت (Skill Tree)** استفاده می‌شود؛ جایی که هر مسیر معادل یک نقش شغلی واقعی در دپارتمان‌های کلیدی رکاد است و هر مأموریت با انجام کاری واقعی روی محصولات باشگاه گره خورده است.

---

## 🎯 ایده محوری و حل مسئله

هنرستان استارتاپی رکاد با یک باشگاه دانش‌آموزی محصول‌محور کار می‌کند (کافه کارآفرینی، ایونت‌ها، طراحی سایت و...). چالش اصلی این بود که بار پروژه‌ها روی دوش عده‌ای محدود می‌افتاد و تازه‌واردها سردرگم می‌شدند. فرستادن افراد به دوره‌های آنلاینِ جدا از پروژه‌ی واقعی هم به دلسردی ختم می‌شد.

**راه‌حل Edukad:**
- هر **مسیر (Roadmap)** معادل یک نقش شغلی است (مثلاً توسعه‌دهنده فرانت‌اند، طراح UI/UX، یا مسئول اجرایی رویداد).
- هر **گره (Node)** در یک مسیر، نماینده‌ی یک مهارت مشخص است.
- یادگیری خطی نیست؛ گراف پیش‌نیازها کاملاً پویاتر و به شکل یک **DAG (گراف جهت‌دار بدون حلقه)** طراحی شده است.
- **مأموریت‌های واقعی:** خروجی هر گره، انجام یک تسک واقعی روی محصولات خودِ رکاد (سایت مدرسه، برندینگ، شبکه‌های اجتماعی) است.
- **یادگیری همتا-به-همتا:** ارشدهای هر رشته (به عنوان **منتور**) کار تازه‌واردها را بررسی می‌کنند.

## 🏗️ معماری و مدل داده‌ها

سیستم به‌صورت یکپارچه اما در یک معماری Full-Stack ماژولار و بر بستر **TypeScript** توسعه یافته است.

### 🛡️ نقش‌ها و سطوح (RBAC)
دسترسی‌ها و سطح تخصص کاملاً از هم ایزوله شده‌اند:
* **نقش سیستمی (`role`)**: کنترل دسترسی روی APIها و نماها (`SUPER_ADMIN`, `MENTOR`, `STUDENT`).
* **سطح پیشرفت (`level`)**: نمایش مهارت فرد در پروفایل شخصی که مستقل از دسترسی سیستمی عمل می‌کند (`NOVICE`, `PRACTITIONER`, `TEAM_LEAD`, `MENTOR_CANDIDATE`).

### ⚙️ دپارتمان‌های تحت پوشش
* **مهندس‌ها (`ENGINEERS`)**: فرانت/بک‌اند، UI/UX، اتوماسیون.
* **آرتیست‌ها (`ARTISTS`)**: گرافیک، ویدیو ادیتور، موشن‌دیزاین، تولید محتوا.
* **آچار فرانسه‌ها (`OPS`)**: عملیات رویداد، دیجیتال مارکتینگ، لجستیک و مدیریت.

### 🚦 ماشین حالتِ پیشرفت گره (State Machine)
گره‌ها مراحل استانداردی را طی می‌کنند:
1. `LOCKED` (پیش‌نیازها کامل نیست)
2. `UNLOCKED` (شروع مطالعه و امکان ارسال مأموریت)
3. `IN_PROGRESS`
4. `SUBMITTED` (منتظر بازبینی منتور)
5. `NEEDS_REVISION` (نیاز به اصلاح - رد شده توسط منتور)
6. `COMPLETED` (تایید نهایی و باز شدن گره‌های بعدی)

## 💻 Tech Stack (تکنولوژی‌های استفاده شده)

* **Backend:** `NestJS`, `TypeScript`, `Prisma` (ORM), `PostgreSQL`
* **Frontend:** `Next.js (App Router)`, `React`, `TailwindCSS`, `React Flow` (برای ترسیم گراف درخت مهارت‌ها)
* **Auth:** سیستم Authentication اختصاصی مبتنی بر `JWT`
* **داکر و زیرساخت:** توسعه و اجرای آسان از طریق `docker-compose`

## 📦 پیش‌نیازها و راه‌اندازی (Installation)

پروژه با ساختار Monorepo طراحی شده است. برای اجرای محلی، مطمئن شوید که **Node.js (نسخه 18+)** و **Docker** نصب شده باشند.

### ۱. اجرای دیتابیس (از طریق Docker)
در پوشه ریشه پروژه:
```bash
docker-compose up -d
```
*با این دستور PostgreSQL روی پورت `5432` با تنظیمات مورد نیاز پروژه اجرا می‌شود.*

### ۲. راه‌اندازی Backend
```bash
cd backend

# نصب وابستگی‌ها
npm install

# کپی و تنظیم متغیرهای محیطی
cp .env.example .env
# اطمینان حاصل کنید که DATABASE_URL تنظیم شده باشد (در فایل .env.example پیش‌فرض‌های داکر وجود دارد)

# اعمال ساختار دیتابیس با Prisma
npm run prisma:push

# (اختیاری) پر کردن دیتابیس با دیتای تست (Seed)
npm run prisma:seed

# اجرای سرور بک‌اند (پورت 4000)
npm run start:dev
```

### ۳. راه‌اندازی Frontend
```bash
cd frontend

# نصب وابستگی‌ها
npm install

# اجرای فرانت‌اند در محیط توسعه (پورت 3000)
npm run dev
```

پلتفرم حالا در آدرس `http://localhost:3000` در دسترس است. بک‌اند هم روی پورت `4000` اجرا می‌شود.

## 🚀 ویژگی‌های شاخص (Key Features)

- 🎨 **استودیو روادمپ (Roadmap Builder):** پنل فوق‌العاده بصری برای `SUPER_ADMIN` مبتنی بر React Flow که ادمین با کشیدن و رها کردن (Drag & Drop) می‌تواند گره‌ها و پیش‌نیازها را مدیریت کند.
- 🔒 **حفاظت منطق گراف (DAG Safety):** سیستم به‌طور سمت-سرور در زمان اتصال گره‌ها از ایجاد چرخه‌های بی‌نهایت (Circular Dependency) با استفاده از الگوریتم‌های گرافی جلوگیری می‌کند.
- 📂 **تاریخچه سابمیت‌های زنده (Immutable Submissions):** با هر بار ارسال تمرین، رکورد جدیدی ثبت می‌شود و رکوردهای قبلی حفظ می‌گردند تا تاریخچه‌ی کاملی از زحمات و رشد یک دانش‌آموز ساخته شود.
- 💬 **فیدبک‌لوپ منتور-دانش‌آموز:** امکان رد یا تایید تمرین‌ها و مأموریت‌ها همراه با یادداشت و فیدبک دقیقِ منتور.
